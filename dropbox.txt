여러 드롭박스 계정을 한 곳에서 관리하는 파일 리스트 웹 프로그램
1. 드롭박스 계정 연결은 드롭박스 홈페이지에서 로그인해서 인증 (OAuth 2.0)
1) 각 계정마다 독립된 토큰을 사용
2. 다중 계정에서 검색하고 싶은 파일/폴더를 한 번에 검색
3. 각 계정의 파일/폴더 목록 출력, 계정마다 각각 가상의 마운트 경로를 생성해서 관리,마운트 경로값은 설정 페이지에서 입력
4. 파일 미리보기 기능
5. video.js v10(https://github.com/videojs/video.js/) 기반 동영상 플레이어,이전 및 다음 재생 버튼,브라우저 화면 내 풀 스크린(웹 풀스크린),풀 스크린,,화질 설정,4K,WMV 기타 파일 및 코덱 원할 재생 지원,음량 조절 등
1)다음 파일 자동 재생 토글,팟플레이어 연결 버튼->플레이어 하단 배치
2)스트리밍 속도 최적화(100Mbps 기준)
3)오라클 클라우드(Ampere A1 4 OCPU(vCore) 24GB RAM) 기반 스트리밍 구조 설계
4)원본 재생 우선, 4K->1080p 및 비지원 코덱 스트리밍
5)기본 스킨 사용
6)오디오 파일도 video.js v10 사용
6. 파일 또는 폴더 다운로드, 여러 파일 및 폴더를 한 번에 다운로드 하는 기능 지원(체크박스,압축)
7. 관리자 페이지 생성
1)관리자 페이지의 저장소 메뉴에서 드롭박스 연결 관리(추가,삭제,목록)
2)관리자 페이지 설정->사이트->Robots.txt 설정 칸
기본값
User-agent: *
Disallow: /
3)관리자 페이지 설정->미리보기->오디오 자동 재생 토글,비디오 자동 재생 토글
4)설정->미리보기->압축 미리보기 토글
5)관리자 페이지 프로필 메뉴->관리자 이름 비밀번호 변경 기능
6)관리자 페이지 진입시 프로필 메뉴 진입
7)프로필,설정,저장소순으로 메뉴 생성
8)왼쪽 사이드 바 메뉴
9)설정->사이트->페이지 매기기 유형(모두,페이지 매기기,더 보기, 자동 더보기)
10)설정->사이트->페이지당 기본 항목 수(기본값:30)
8.이미지 파일 왼쪽 아이콘 클릭 시 lightGallery(https://github.com/sachinchoolur/lightgallery) 원본 이미지 열기
9.파일 및 폴더 이름 마우스 우클릭 메뉴(새 탭에서 열기,이름 바꾸기,이동,복사,삭제,링크 복사,다운로드)
10.이름,크기,수정 시간 순으로 표시
11.상단 검색 아이콘,list(목록) SVG 아이콘(목록보기,이미지 보기)
12.검색 페이지에서 전체,폴더,파일 검색 기능
13.다크 테마 기본
14.VR 180,360 비디오 지원(확대,축소 기능)
15.미리보기 미사용시에 사용하거나 별도로 진입할 수 있는 다운로드 탭 구현(파일 이름&확장자, 용량, 날짜 표시,링크 복사와 다운로드 버튼 배치)
16.이름,비밀번호로 사이트 접근 관리 및 보안 구축
17.초기 관리자 이름 admin, 비밀번호 1234
18.로컬 윈도우 실행 및 오라클 클라우드(Ampere A1 4 OCPU(vCore) 24GB RAM) portainer->docker compose 배포
19.하단 관리(관리자) 링크
20.저장소 추가->마운트 경로 input 박스,캐시 만료 시간(분,해당 저장소) 설정 기본값 30
21.디렉토리 목록이나 토큰, 썸네일 등의 데이터를 임시로 저장하는 캐시
22.캐시 Memory Leak 방지
23.캐시 cleanup interval 설정,기본값 120(초)
24.필요할 경우 config.json 생성
25.마운트 가상 경로 예제. /path/to
26.마운트 경로 중복 검사
27.디렉토리 이름,크기,수정 시간 정렬(각 항목 반복 클릭시 오름차순,내림차순 반복)
28.lightGallery 플러그인 lg-zoom으로 마우스 스크롤로 확대,축소 기능 추가
1)그대로 사용 불가능할 경우 소스코드 수정
29.메인페이지에 저장소 목록 출력(관리자 페이지 매기기 유형 설정값 사용) 밎 탐색
30.등록할 계정이 100개 이상을 가정하고 전체 기능 설계
31.관리자 저장소 페이지에서 모든 저장소를 스크롤로 출력
32.폴더 크기 표시(오른쪽 마우스 메뉴)
33.로컬 윈도우 실행 스크립트
34.마운트 경로 요약 없이 표시(각 경로 클릭 시 바로 이동 가능)(상단과 탐색창 사이의 빈 공간)
